# 研究方法

[返回首页](../README.md) · [完整报告](../RESEARCH_REPORT.md)

## 从价格到组合

1. 对齐八只 ETF 复权收盘价，验证日期、缺失和价格有效性。
2. 月末计算动量 `P(t−21) / P(t−252) − 1` 和趋势 `P(t) / SMA200(t) − 1`。
3. 在七只风险资产中筛选两个因子均为正的资产，按动量取前二，各配置 50%；不足部分持有 SHY。
4. 下一交易日收盘执行，按自然漂移后的持仓计算成交额和费用。
5. 保存逐日净值、权重、费用与月度信号，分别评估开发、验证和历史测试区间。

## 信号与收益时序

| 时间 | 动作 | 收益归属 |
| :--- | :--- | :--- |
| 月末 t 收盘后 | 因子计算与目标权重生成 | 旧仓位 |
| t+1 收盘 | 调仓并扣费 | 当日收盘到收盘收益属于旧仓位 |
| t+2 起 | 持有调仓后的组合 | 新仓位 |

价格变动使权重自然漂移，日间不自动再平衡。初次建仓计费，研究终点按市值估值，不假设清仓。

## 统计与预测

- **因子 IC**：七资产横截面秩相关，目标为执行日到下次执行日的非重叠收益。
- **HAC 检验**：按月份计算，使用 3 阶 Bartlett 权重，报告渐近正态近似 p 值。
- **滚动预测**：逐月扩展训练窗口，标签结束日必须早于预测日；标准化只在训练集估计。
- **预测基准**：训练期全部资产收益均值，比较 MSE 与样本外 R²。
- **超额收益区间**：对策略减等权的日收益做 21 日循环区块 bootstrap，重复 2,000 次。

## 风险与费用口径

年化因子为 252。最大回撤在各区间从净值 1 重新计算；CVaR 为样本最差 5% 日收益均值。`Sharpe_vs_SHY` 使用相对 SHY 的收益计算，不是使用现金无风险利率的标准夏普。

成本按买卖两侧分别计费。`annual_traded_notional` 是买卖成交金额合计相对净值的年化值，不是除以二的单边换手率。

## 实现检查

内置检查覆盖未来价格扰动不影响历史信号/净值、训练标签成熟性、权重约束、下一收盘执行和费用守恒，摘要见 [tests.txt](../results/tests.txt)。历史时间切分不等同于前瞻验证；资产选择与数据版本偏差仍需单独评估。
