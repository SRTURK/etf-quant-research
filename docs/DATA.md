## 来源与范围

原始文件来自 [manisahni/marketdata](https://github.com/manisahni/marketdata) 的 `daily_adjclose.csv`。维护者声明其来自 yfinance 复权收盘价缓存，该声明不等同于独立供应商核验。

| 项目 | 口径 |
| :--- | :--- |
| 原始快照 | 5,688 行，2004-01-02 至 2026-08-11 |
| 研究范围 | 八只 ETF，截至 2025-12-31，排除 2026 年 |
| 共同有效起点 | 2004-11-18；清洗后 5,313 行 |
| 预热期 | 2004–2005，组合从 2006 年开始 |
| 收益口径 | 拆分及分红复权价之比，不重复加分红 |

## 清洗与审计

日期必须唯一且递增，价格必须为正且有限。共同起点后出现缺失即停止，不进行填充或缩尾。绝对日收益超过 15% 的样本单列供核查，保留危机期间的波动。

VIX 锚点、SPY 极端日及节假日检查只用于基本合理性验证。尚未独立核验完整交易所日历、分红与拆分事件，也未取得 OHLCV 或逐日封存的数据版本。

## 快照恢复

研究默认读取仓库内快照。仅当文件丢失时运行 `python fetch_data.py`。下载内容必须匹配固定哈希，否则拒绝覆盖。引入新数据版本时，应更新数据审计、时间区间与研究结论。

## 使用限制

ETF 池由现存基金构成，未包含清盘、合并基金及历史流动性筛选。共同上市日期过滤不消除生存者偏差。快照可能包含供应商事后修订；数据使用及再分发权限应按原提供方条款核实。
